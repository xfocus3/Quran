# Quran build and implementation contract

Use REA and retained artifacts before reconstruction. Keep source-derived facts,
runtime observations, inferences and unknowns distinct. Preserve Quran/tafsir
identity, original Unicode, provenance and the three Arabic books.

Local Sandcastle performs implementation and independent review. Trusted GitHub
Actions on this public repository may build and run Android 15+ emulators/tests.
Do not upload credentials, signing keys, original APKs, personal information,
private evidence or plaintext private build inputs/results. Never give private
inputs or secrets to pull requests, forks or untrusted workflow code. Keep local
Android Docker stopped; no real-phone access before the final owner checkpoint.

Green CI validates only its named coverage. It does not approve matching to the
original app, satisfy human checkpoints, merge implementation slices or close
issues. Preserve blockers and unknown original behaviors. Reference comparisons
must bind to the exact source and APK under review.

For UI work use DesignExpert with an original-constrained design brief before
editing, and perform visual/accessibility QA. Use human task-focused Conventional
Commits without assistant/model naming or attribution. Keep this repository's
public boundary explicit when exporting another private candidate.
